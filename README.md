## Déploiement gratuit sur Render

1. Crée un compte sur [https://render.com](https://render.com)
2. Crée un nouveau **Web Service**
3. Connecte ton repo GitHub (ou upload le dossier)
4. Configure :
   - **Runtime**: Node
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
5. Clique sur **Create Web Service**

Ton casino sera en ligne en quelques minutes.

## Lancer en local

```bash
npm install
npm start
```
